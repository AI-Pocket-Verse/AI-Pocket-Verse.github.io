网连隐私政策

生效日期：2026 年 8 月 11 日 · 最近更新：2026 年 9 月 1 日（自 1.6.0 版本起适用）

适用范围：macOS 应用「网连」（Bundle ID：com.netlink.app）

English version · 英文版

网连是一款本地网络环境检测工具，用于查看本机网络、公网出口、代理/VPN 风险、DNS、IPv6、系统环境和硬件概览，并提供 AI 服务可用性检测、带宽测速、多地探测、域名诊断和报告导出等检测能力。我们不收集任何用户信息，不提供账号系统，不展示广告，不进行跨应用或跨网站追踪，也不运营用于接收、保存或分析用户数据的服务器。应用不申请也不读取定位、麦克风、相机、通讯录等系统隐私权限，所有检测结果和历史记录仅保存在你的 Mac 本机。

1. 我们如何理解 Apple 的隐私披露要求

Apple 要求开发者在 App Store Connect 中准确披露应用以及第三方服务实际收集、使用和传输的数据，并保持隐私政策、App 隐私标签和应用行为一致。我们据此说明网连作为本地工具会在设备本机处理哪些信息、检测过程中可能访问哪些第三方服务，以及用户在国内或弱网环境下应如何理解检测结果。

2. 本应用不会做的事

  • 我们不会收集、接收、保存或分析你的个人信息。
  • 不会要求注册账号或登录。
  • 不会向开发者自有服务器上传你的检测结果。
  • 不会出售用户数据。
  • 不会将数据用于广告投放、广告归因或跨应用追踪。
  • 不会请求或读取定位（Core Location）权限，也不会将用户引导到「系统设置 › 隐私与安全性 › 定位服务」去授予权限。
  • 不会读取通讯录、照片、相机、麦克风、日历或蓝牙等系统隐私数据。
  • 不会读取 Safari 等其他应用的偏好设置；相关项目仅提示用户手动核对。

3. 本机处理的信息

为了完成网络环境检测，网连会在你的 Mac 本机读取、计算和展示以下信息。这些信息由应用在本机使用，我们不会收集或上传：

  • 网络信息：本机局域网 IP、DNS 服务器、IPv6 可用性、系统代理配置（HTTP/HTTPS/SOCKS/PAC 的启用状态与目标地址）、网络接口类型和网络变化状态。
  • 公网出口信息：公网 IP、国家或地区、城市、ISP、组织、时区、代理/VPN/Tor/数据中心/爬虫标记、多源 IP 一致性结果。
  • 风险检测结果：IP 风险评分、代理风险、垃圾记录命中情况和检测错误信息。
  • 系统环境信息：系统时间、时区、语言与区域、IPv6 风险提示。
  • 硬件概览：CPU 型号、内存容量、GPU 名称、显示器厂商/型号/序列信息、设备序列号、网络接口 MAC 地址。
  • 环境档案：由本机局域网子网线索、接口类型和 DNS 列表在本机计算的网络环境指纹（不读取 Wi-Fi 名称/SSID，不使用定位），用于识别「同一个网络环境」并记录首末次出现时间。
  • 自定义皮肤图片：你在设置中主动选择的背景图片会缩小后保存于本机数据目录，仅用于窗口背景展示，不上传；可在设置中随时移除。
  • 网络事件时间线：公网 IP、局域网、DNS、时区不一致等事实变化的本机记录。
  • 连接诊断结果：连接分段耗时（DNS/TCP/TLS/首字节）、直连与系统代理对比、测速与多地探测结果——仅在你主动发起检测时产生并展示。
  • 应用设置：菜单栏显示偏好、通知偏好、菜单栏点击行为、悬浮挂件与告警规则开关等。

上述硬件和系统信息仅用于在应用界面中向你展示当前设备环境，保存在本机，不会上传至开发者服务器。包括设备序列号、网络接口 MAC 地址、显示器序列信息在内的硬件标识信息不会离开你的设备，不会发送给任何第三方服务，也不会用于任何形式的用户识别、设备指纹或追踪。

4. 本机保存的信息

网连会在本机保存必要的应用状态，以便下次启动时恢复最近一次检测结果：

  • 最近一次检测快照，包括公网、网络、系统、硬件和评分等结果。
  • IP 历史、安全评分历史、网络事件时间线和环境档案。
  • 用户偏好设置，使用 macOS 的 UserDefaults 或应用支持目录保存。
  • 应用内购买的解锁状态与免费试用的起始时间：购买本身由 Apple 的 StoreKit 处理，应用仅在本机记录状态，不上传。

这些数据存储在你的 Mac 本地。卸载应用或手动清理应用数据后，这些本机记录可能会被删除。你也可以随时在「设置 › 隐私」中使用「一键清除检测痕迹」删除检测快照、IP 历史、评分历史、环境档案与事件时间线（应用设置与购买状态不受影响）。

报告导出（PDF / Markdown / JSON / CSV / 分享卡片 PNG）完全在本机生成，文件保存位置由你在系统保存面板中选择；导出过程不联网，导出内容不会上传给开发者或任何第三方。

5. 第三方网络服务

网连本身不收集任何信息，也不将数据发送给开发者服务器。部分检测功能需要你的设备直接访问第三方网络服务，以判断公网出口、IP 地理位置、代理/VPN 标记、风险和连通性。访问这些服务时，你的公网 IP 地址和常规网络请求信息会被相应第三方服务接收，这是完成实时检测所必需的。

  • https://ipwho.is/：用于获取公网 IP、地理位置、ISP、时区等信息。
  • https://api.ipapi.is/：用于获取 VPN、代理、Tor、数据中心、ASN 等安全信息。
  • https://1.1.1.1/cdn-cgi/trace：用于辅助验证公网出口 IP。
  • https://proxycheck.io/：用于获取 IP 风险评分和代理风险信息。
  • https://api.stopforumspam.org/：用于查询 IP 是否出现在公开垃圾记录中。
  • 连通性检测目标：Claude、ChatGPT、Gemini、Perplexity、Google、YouTube、GitHub、X、Wikipedia、Cloudflare 等站点。
  • AI 服务可用性检测端点：https://api.openai.com/、https://api.anthropic.com/、https://generativelanguage.googleapis.com/、https://api.mistral.ai/、https://api.x.ai/、https://api.cohere.com/。请求不携带任何 API Key、不发送用户标识，仅按响应状态码与响应体中的公开错误码特征在本机判定「鉴权拒绝（服务正常）」或「区域拒绝」；仅在你主动发起检测或开启定时探测时访问。
  • https://speed.cloudflare.com/：带宽测速端点。测速会按你选择的档位产生真实的下载/上传流量（应用会在开始前显示预计流量），这些请求会到达 Cloudflare 的测速端点，Cloudflare 可能按其自身政策记录并聚合请求信息。
  • https://api.globalping.io/：多地探测（Globalping 志愿探针网络）。发送内容为你输入的探测目标（域名或 IP），由分布在多个大区的第三方志愿探针节点执行 ping / traceroute。如果你选择探测自己的公网 IP，该 IP 会被发送至这些第三方志愿节点——应用会在你首次使用该功能前弹出一次性确认。
  • 公共 DoH 解析器（域名诊断）：cloudflare-dns.com、dns.google、dns.alidns.com、doh.pub。发送内容为你输入的域名，用于多解析器解析一致性比对。
  • https://crt.sh/：证书透明度公开日志查询。发送内容为你输入的域名。
  • https://captive.apple.com/：Apple 官方热点检测页，用于判断当前网络是否存在强制登录门户；请求内容为固定探测页，不含个人数据。

此外，连接分段耗时诊断、域名诊断（端口连通性、TLS 证书链）会按你的指令直接向你输入的目标 URL 或域名发起网络请求；目标服务器会因此接收到来自你设备的常规网络请求。请只对你有权检测的目标使用这些功能。

这些第三方服务由各自运营方控制。我们不会从这些第三方服务接收或保存你的个人信息；它们如何处理访问日志、IP 地址和请求信息，适用其各自的隐私政策与服务条款。

6. 中国大陆及弱网环境下的可达性说明

部分第三方检测服务和连通性目标位于中国大陆以外，可能因地区政策、网络路由、运营商策略或服务自身限制而无法访问。不可达并不一定代表你的本机网络故障。

当公网或风险检测请求失败时，网连会显示失败原因；如果本机存在上次成功检测结果，应用可能展示旧结果，并明确标注为“上次成功检测结果”。旧结果不应被理解为本次检测成功。

7. 数据用途

网连在本机处理上述信息仅用于以下目的：

  • 展示当前网络和公网出口环境。
  • 识别可能的代理、VPN、Tor、数据中心或 DNS/IPv6 风险。
  • 计算本机网络环境安全评分。
  • 保存历史检测记录，便于用户回看网络变化。
  • 根据用户设置显示菜单栏状态、通知或应用界面。

8. 数据共享

我们不收集、不上传、不共享你的本机检测记录。应用访问第三方检测服务时，第三方服务会因网络请求而接收到你的公网 IP 地址和请求元数据。除此之外，网连不会主动向任何第三方提交你的本机硬件概览、历史记录或应用设置。

9. 数据安全

网连使用系统提供的沙盒和网络权限运行（仅出站网络，无入站监听）。公网数据接口均使用 HTTPS，不包含明文 HTTP 的公网数据接口；域名诊断中的端口连通性检查会按你的指令向目标主机发起 TCP 连接尝试，仅用于判断端口是否可达，连接建立后立即断开，不发送应用数据，也不传输可识别个人的内容。请注意，任何互联网请求都可能被目标服务记录访问时间、IP 地址、User-Agent 或其他基础请求信息。

10. 用户控制

  • 你可以选择不运行检测，或避免使用会访问第三方站点的风险检测、连通性检测、测速、多地探测与域名诊断功能——这些检测都只在你主动发起时才联网。
  • 你可以在应用设置中调整菜单栏图标、通知、悬浮挂件与告警规则等偏好。
  • 你可以在「设置 › 隐私」中使用「一键清除检测痕迹」，或通过删除应用数据、卸载应用来清理本机保存的历史记录。
  • 多地探测的「探测自己的公网 IP」需要你首次使用前明确确认。
  • 你可以在 macOS 系统设置中管理应用通知、登录项和网络相关权限。

11. 儿童隐私

网连不是面向儿童设计的应用，不包含社交、广告、账号或用户画像功能。我们不会有意收集儿童个人信息。

12. 隐私政策更新

如果网连后续新增账号、云同步、自有服务器、广告、分析 SDK 或新的第三方服务，我们会更新本隐私政策，并在 App Store Connect 中同步更新 App 隐私信息。（报告导出已于 1.5.0 版本提供，其隐私实践见第 4 节：完全本机生成，不上传。）

13. 联系我们

如果你对本隐私政策或数据处理方式有疑问，请通过 App Store 产品页中列出的开发者联系方式或支持网站与我们联系。

本政策用于说明网连当前版本的隐私实践，不构成法律意见。提交 App Store 或其他应用市场前，请结合实际运营主体、联系方式、隐私标签和当地法律要求进行最终确认。
