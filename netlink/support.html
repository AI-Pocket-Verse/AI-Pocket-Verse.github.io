2. 主要功能

  • 智能检测：汇总当前网络、系统环境和安全评分。
  • 本机网络：展示局域网 IP、DNS、IPv6 状态和网络类型。
  • 公网信息：展示公网 IP、地区、运营商、组织、时区和出口一致性。
  • 代理检测：辅助识别系统代理、VPN、Tor、数据中心或托管网络特征。
  • IP 风险：通过第三方服务查询公开风险信号和代理风险。
  • 连通性检测：检查常用站点和 AI 服务的网络可达性。
  • 历史记录：在本机保存最近检测结果、IP 历史和安全评分历史。
  • 环境概览：展示系统、时区、语言、硬件和显示器相关信息。

3. 常见问题

为什么检测结果会显示失败？

公网、风险和连通性检测依赖外部网络服务。若当前网络较弱、DNS 异常、运营商路由不稳定，或目标服务在所在地区不可达，检测可能失败。失败不一定代表本机网络故障。

为什么国内网络下部分服务不可达？

部分检测目标和第三方服务位于中国大陆以外，可能受地区政策、网络路由、运营商策略或服务自身限制影响。网连会尽量显示失败原因，但无法保证所有第三方服务在所有地区都可访问。

为什么显示“上次成功检测结果”？

当本次公网检测失败但本机存在旧结果时，网连可能展示上次成功检测结果，并在界面中标注。该结果仅供参考，不代表本次检测成功。

网连会上传我的硬件信息或历史记录吗？

不会。硬件概览、系统环境、历史记录和应用设置仅保存在你的 Mac 本机。网连不运营用于接收、保存或分析用户数据的开发者服务器。

为什么 IP 地理位置不准确？

IP 地理位置由第三方数据库提供，可能因运营商出口、代理、VPN、企业网络、CDN 或数据库更新延迟而不准确。网连展示的是检测服务返回的结果，不代表设备的精确物理位置。

网连是否需要登录或订阅？

当前版本不提供账号系统，不需要登录，不包含订阅或应用内购买。

4. 故障排查步骤

  1. 确认 Mac 已连接网络，并能在浏览器中打开常用网站。
  2. 关闭或切换 VPN、代理、网络加速器后重新检测，观察结果是否变化。
  3. 切换 Wi-Fi、热点或其他网络环境，排除单一网络线路问题。
  4. 检查系统时间、时区和 DNS 设置是否异常。
  5. 退出并重新打开网连，然后再次点击检测。
  6. 如果问题持续存在，请将问题截图、macOS 版本、App 版本、当前网络环境和复现步骤发送至 venshine.cn@gmail.com。
请不要在邮件中发送密码、验证码、证件号码、支付信息或其他敏感个人信息。

5. 隐私与数据说明

网连是一款本地工具，不收集任何用户信息，不提供账号系统，不展示广告，不进行跨应用或跨网站追踪。应用产生的检测结果和历史记录仅保存在你的 Mac 本机。

部分检测功能需要你的设备直接访问第三方网络服务，以判断公网出口、IP 地理位置、代理/VPN 标记、风险和连通性。访问这些服务时，你的公网 IP 地址和常规网络请求信息会被相应第三方服务接收，这是完成实时检测所必需的。

完整说明请阅读 网连隐私政策。

6. 第三方服务说明

网连可能直接访问以下第三方服务或目标站点，用于公网信息、风险识别和连通性检测：

  • https://ipwho.is/
  • https://api.ipapi.is/
  • https://1.1.1.1/cdn-cgi/trace
  • https://proxycheck.io/
  • https://api.stopforumspam.org/
  • Claude、ChatGPT、Gemini、Perplexity、Google、YouTube、GitHub、X、Wikipedia、Cloudflare 等连通性检测目标。

这些服务由各自运营方控制。网连不会从这些服务接收或保存你的个人信息；第三方如何处理访问日志、IP 地址和请求信息，适用其各自的隐私政策与服务条款。
